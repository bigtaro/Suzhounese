# 苏州话语料获取方案

> 日期：2026-11-20  
> 目标：获得 50–100 小时可用于苏州方言 ASR 训练的语音数据。

## 1. 当前结论

- 当前工作区没有音频数据。
- 本机可用磁盘约 248 GB，存储 100 小时 16 kHz 单声道 WAV 足够。
- 当前执行环境无法解析外网域名，不能直接下载公开语料。
- 50–100 小时苏州话通常不是单一公开下载包，常见情况是需要采购授权、学术申请或自行采集。
- 不应从视频网站、播客、广播等来源抓取版权不明音频来凑时长。

## 2. 推荐的数据构成

不建议把“50–100 小时”全部理解为精标数据。更现实的组合是：

| 数据类型 | 建议时长 | 用途 |
|---|---:|---|
| 精标训练集 | 20–50 小时 | 监督微调，决定模型上限 |
| 精标验证/测试集 | 3–5 小时 | 说话人隔离评测 |
| 无标注或伪标注数据 | 30–70 小时 | 自训练、继续预训练、扩充场景 |

总计 50–100 小时音频，其中 20–50 小时为高质量人工转写。数据多样性通常比单纯增加同一批说话人的时长更重要。

## 3. 三条获取路径

### 路径 A：采购或申请已有语料

优先寻找已经有转写、说话人信息和明确许可证的数据包。可核查的来源类型包括：

- 公开语音数据集平台：OpenSLR、Hugging Face Datasets、ModelScope。
- 商业数据商：LDC、MagicData、SpeechOcean 等，确认是否提供苏州话或吴语包。
- 高校和科研机构：苏州大学、复旦大学、上海大学、中国社会科学院语言研究所等方言研究团队。
- 地方机构：苏州广播电视总台、苏州图书馆、地方志/档案馆的口述历史或方言录音。

每个来源都要核实：

- 是否有 50–100 小时，或能否分批采购。
- 音频是否包含逐句转写。
- 是否有说话人、年龄、性别、地区、录音设备等元数据。
- 许可证是否允许训练、修改和商用。
- 是否允许再次分发模型或数据。
- 方言点是否与目标口音一致。

没有书面授权和明确许可证的数据，不进入训练集。

### 路径 B：自行采集

这是最容易控制口音、场景和授权的方式，但需要时间和人力。

100 小时的一种可行组合：

- 200 位说话人 × 30 分钟 = 100 小时。
- 或者 300 位说话人 × 20 分钟 = 100 小时。
- 建议 50%–70% 朗读/提示语料，30%–50% 自然对话。
- 每位说话人尽量覆盖安静室内、普通家庭环境和少量噪声场景。

采集基本要求：

- 优先 48 kHz 原始录音，保留原始文件，再统一转换为 16 kHz 单声道训练副本。
- 每人单独文件，记录 `speaker_id`、`session_id`、年龄、性别、地区、设备和环境。
- 录音前签署知情同意书，说明用途、保存期限和撤回方式。
- 说话人编号匿名化，不在文件名中使用真实姓名。
- 单人单次录制建议 15–30 分钟，避免疲劳导致发音不自然。

### 路径 C：已有音频 + 伪标注

如果已经有授权但未转写的音频，可以先用基础模型生成伪标签，再由母语者校对高价值片段。

- 先精标 10–20 小时作为种子集。
- 用种子模型转写剩余音频。
- 按置信度、说话人多样性和场景多样性筛选。
- 人工抽检并修正，不能把未校验的伪标签全部当金标准。
- 逐步迭代，优先修正高置信度但明显错误的样本。

## 4. 采集内容设计

### 4.1 朗读/提示语料

- 常用词、数字、时间、地点、亲属称谓。
- 苏州地名、人名、店名、公交站名。
- 覆盖不同声母、韵母、声调和连读变调的短句。
- 普通话/苏州话混说句。

### 4.2 自然对话

- 家庭、买菜、看病、问路、工作、闲聊等日常主题。
- 双人对话和少量多人对话。
- 保留自然停顿、语气词、重复和口误；是否保留由标注规范决定。

### 4.3 场景覆盖

- 安静室内。
- 家庭/办公室普通背景噪声。
- 电话或手机录音。
- 少量远场/客厅场景。

不要只采安静朗读数据，否则真实对话场景会明显掉点。

## 5. 存储与文件组织

100 小时 16 kHz、16-bit、单声道 WAV 约 11–12 GB；保留 48 kHz 原始文件会更大，但仍在本机容量范围内。

建议目录：

```text
data/
├── raw/                 # 原始录音，不直接改写
├── interim/             # 重采样、切分后的中间文件
├── manifests/           # train/dev/test 清单
├── annotations/         # 人工转写和校对结果
└── licenses/            # 授权书、许可证和采集记录
```

文件命名示例：

```text
S001_20261120_01.wav
S001_20261120_01.json
```

清单字段至少包含：

```json
{
  "utt_id": "sz_000001",
  "audio": "data/interim/S001/S001_20261120_01.wav",
  "speaker_id": "S001",
  "session_id": "S001_20261120_01",
  "split": "train",
  "duration": 6.4,
  "text_ortho": "苏州话汉字转写",
  "region": "城区",
  "age": 65,
  "gender": "F",
  "noise": "clean",
  "license_id": "CONSENT-001"
}
```

## 6. 质量验收

拿到或采到数据后，先做自动检查，再进入标注：

- 采样率、声道数、位深和时长是否符合要求。
- 静音比例是否过高，是否存在空文件或截断文件。
- 是否有重复音频、重复说话人或同一场录音跨训练/测试集。
- 试听 5% 随机样本，检查爆音、削波、底噪和串音。
- 统计说话人数量、年龄/性别/地区分布和每人时长。
- 统计朗读/对话、安静/噪声、纯方言/混说比例。
- 对 30–60 分钟试标数据做双人一致性检查。

## 7. 合规要求

- 每条音频都要能追溯到授权来源或知情同意记录。
- 不使用未授权的影视、综艺、短视频、播客和广播音频。
- 不在公开仓库提交原始音频、个人信息或未脱敏转写。
- 数据删除和撤回请求要有处理流程。
- 训练出的模型卡中说明数据来源、适用范围和已知偏差。

## 8. 下一步需要确认

1. 你是否有已授权的苏州话音频、网盘链接或数据商账号。
2. 目标口音是苏州城区，还是也要覆盖吴江、昆山、常熟、张家港、太仓。
3. 你能接受“20–50 小时精标 + 30–70 小时无标注/伪标注”的组合吗。
4. 是否能组织本地母语者采集和校对。
5. 预算和时间窗口是多少。

确认后可以继续做：下载/导入脚本、音频格式检查、VAD 切分、清单生成、说话人隔离切分和语料统计报告。
