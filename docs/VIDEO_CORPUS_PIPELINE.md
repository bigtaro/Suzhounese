# 用有字幕视频构建苏州方言语料

> 目标：把有授权的视频转换成可训练的苏州话 ASR 语料。  
> 原则：先确认版权和字幕性质，再做切分、转写、对齐和质检。

## 1. 先判断两个关键问题

### 1.1 视频是否有使用授权

只处理满足以下条件之一的视频：

- 你自己拍摄并拥有版权。
- 版权方书面授权用于语音识别训练。
- 视频使用明确允许训练、修改和再分发的许可证。
- 平台条款和当地法律允许你下载并用于该目的。

不要直接抓取版权不明的影视、综艺、短视频或播客。原始视频、字幕和转写都可能涉及版权和个人信息。

### 1.2 字幕是不是“苏州话逐字转写”

这是最重要的判断。很多视频字幕是普通话翻译或意译，并不是说话人实际说的苏州话。

| 字幕类型 | 能否直接当 ASR 标签 | 处理方式 |
|---|---|---|
| 苏州话逐字转写 | 可以作为初稿 | 母语者校对错字、语气词和连读变调 |
| 普通话意译 | 不能 | 只能作为语义参考，必须重新转写苏州话 |
| 自动生成字幕 | 通常不能 | 只能作为伪标签，需人工校对 |
| 只有时间轴、无文字 | 不能 | 先做语音转写 |
| 烧录在画面里的字幕 | 视内容而定 | OCR 后仍需校对，不能直接信任 |

如果字幕是普通话翻译，训练目标应写成“苏州话逐字转写”，另存 `text_mandarin` 作为翻译参考；不要用普通话字幕直接训练 ASR。

## 2. 总体流程

```text
视频清单与授权
  -> 下载/导入
  -> 提取音频
  -> 提取软字幕或 OCR 硬字幕
  -> 字幕清洗和时间轴修正
  -> VAD 切分
  -> 说话人分离
  -> 苏州话逐字转写/人工校对
  -> 文本规范化
  -> 质量抽检
  -> 按视频/说话人隔离切分
  -> 导出 JSONL + 音频片段
```

建议先拿 3–5 个视频做 30–60 分钟试点，确认字幕质量、切分效果和人工成本，再批量处理。

## 3. 分步操作

### 3.1 建立视频清单

每条视频至少记录：

- `video_id`
- 来源 URL 或本地路径
- 版权/授权说明
- 视频时长
- 说话人数
- 方言地区
- 字幕类型：软字幕、硬字幕、无字幕
- 字幕是否逐字、是否普通话意译
- 音频质量、背景音乐、噪声

建议保留授权截图、邮件或合同编号，不要只写“网上找的”。

### 3.2 提取音频

保留原始视频或原始音频，另外生成训练副本：

```bash
ffmpeg -i input.mp4 -vn -ac 1 -ar 16000 -c:a pcm_s16le output.wav
```

训练副本统一为 16 kHz、单声道、PCM WAV。不要对原始文件做不可逆降噪；降噪可能破坏声调和擦音。

### 3.3 提取字幕

软字幕可以直接抽取：

```bash
ffmpeg -i input.mkv -map 0:s:0 subs.srt
```

硬字幕需要先定位字幕区域，再做 OCR。OCR 后重点检查：

- 错字、漏字、重复字。
- 标点、数字、英文和专有名词。
- 字幕与音频是否同步。
- 是否把背景文字、弹幕或台标识别进来。

字幕时间轴通常比语音边界宽或窄，后续要用 VAD 和人工试听修正。

### 3.4 字幕清洗

- 合并过短的连续字幕。
- 删除音乐、掌声、笑声等非语音提示，除非你决定保留。
- 删除“主持人：”“旁白：”等说话人标签，改放到元数据。
- 修正重叠字幕和跨句断行。
- 统一标点、数字和英文写法。
- 保留原始字幕文本，另存清洗后的版本，方便追溯。

### 3.5 音频切分

推荐规则：

- 以字幕边界和 VAD 静音点共同确定切分点。
- 每条 5–30 秒，Whisper 训练不超过 30 秒。
- 前后保留 100–300 ms 余量，避免切掉字头字尾。
- 不要在词中间硬切。
- 背景音乐、唱歌、多人重叠严重的片段单独标记或剔除。

切分后统计每条音频的语音占比，语音占比过低的片段不要进入训练集。

### 3.6 说话人分离

单人视频可以直接使用一个 `speaker_id`。访谈、对话和多人节目建议做说话人分离：

- 自动分离可以用 pyannote 等工具。
- 自动结果必须人工抽检和修正。
- 字幕跨说话人时，按说话人转折点重新切分。
- 重叠说话片段建议标记 `overlap=true`，首版训练可以排除。

不要把同一段音频同时标成多个说话人后直接训练。

### 3.7 苏州话逐字转写

这是最耗人力的一步。建议先做 30–60 分钟试标，确定规范：

- 写说话人实际说的苏州话，不写普通话意译。
- 语气词、停顿、重复和口误是否保留。
- 本字、俗字、同音字的优先级。
- 数字、英文、普通话混说的写法。
- 听不清的字如何标记，例如 `[听不清]`，不要猜。

可以用 Whisper/Paraformer 生成初稿，再由母语者校对，但初稿不能直接当金标准。

### 3.8 文本规范化

保留两份文本：

- `text_raw`：原始字幕或 OCR 结果。
- `text_ortho`：最终用于训练的苏州话转写。

可选增加：

- `text_mandarin`：普通话意译。
- `text_phone`：苏州话拼音或 IPA。

标准化时统一简繁体、数字、标点和空格，但不要改变实际发音对应的字。

### 3.9 强制对齐

首版不建议追求字级或音素级对齐。先用“音频片段 + 句子级文本”训练。

如果确实需要精细对齐：

- 使用苏州话发音词典或 G2P 生成发音。
- 用 MFA 等工具做音节级对齐。
- 不要直接用普通话发音词典强行对齐苏州话。
- 检查对齐置信度，低置信度片段人工复核。

### 3.10 质量抽检

每条视频至少检查：

- 字幕和音频同步误差是否可接受。
- 切分点是否切在字中间。
- 转写是否真的对应苏州话发音。
- 是否混入背景音乐、广告、掌声或无关语音。
- 说话人标签是否正确。
- 是否有重复片段或同一视频跨训练/测试集。

建议抽检 10% 片段，双人复核 5%–10%。错误率高的视频整条退回重做。

## 4. 数据清单格式

```json
{
  "utt_id": "sz_video_0001_0003",
  "video_id": "video_0001",
  "source_url": "授权来源地址",
  "license_id": "LICENSE-001",
  "audio": "data/interim/video_0001/0003.wav",
  "start": 12.34,
  "end": 18.90,
  "speaker_id": "S001",
  "region": "城区",
  "age": 62,
  "gender": "F",
  "text_raw": "原始字幕",
  "text_ortho": "苏州话逐字转写",
  "text_mandarin": "普通话意译，可选",
  "subtitle_type": "soft",
  "subtitle_is_verbatim": false,
  "overlap": false,
  "noise": "clean",
  "split": "train"
}
```

## 5. 数据切分

- 必须按 `video_id`、`speaker_id` 和 `session_id` 隔离。
- 同一个视频不能同时出现在训练集和测试集。
- 同一个说话人尽量只出现在一个集合；如果数据太少，至少保证测试集说话人未见。
- 测试集要覆盖朗读、自然对话、老年人、噪声和普苏混说。
- 训练集和测试集不能共享同一段字幕或同一段音频。

## 6. 工具建议

| 环节 | 工具 |
|---|---|
| 下载/导入 | 授权范围内的 yt-dlp、浏览器下载、本地拷贝 |
| 音视频处理 | ffmpeg、ffprobe |
| 字幕提取 | ffmpeg、Subtitle Edit |
| 硬字幕 OCR | PaddleOCR、VideoSubFinder 等 |
| VAD | Silero VAD、pyannote |
| 说话人分离 | pyannote |
| 伪标注 | Whisper、Paraformer |
| 对齐 | MFA + 自定义苏州话发音词典 |
| 标注/校对 | ELAN、Praat、Audacity、Label Studio |

## 7. 规模与成本估算

- 1 小时视频通常只能得到 30–60 分钟可用语音。
- 准备 50 小时可用语料，可能需要 100–200 小时源视频。
- 字幕是逐字转写时，校对成本较低；字幕是普通话意译时，接近重新转写。
- 1 小时音频的方言逐字转写通常需要 4–10 小时人工，具体取决于音质和说话人。

先做小规模试点，统计“每小时源视频能产出多少分钟可用语料”，再决定批量采购或自采。

## 8. 常见坑

- 把普通话字幕当苏州话标签：模型会学成翻译或普通话改写。
- 直接按字幕时间轴切分：字幕边界经常比语音宽，容易切坏字。
- 只按随机片段切分：同一说话人和同一视频泄漏到测试集。
- OCR 后不校对：错字和背景文字会进入训练标签。
- 过度降噪：破坏声调、擦音和入声特征。
- 忽略背景音乐和重叠语音：模型学到非语音模式。
- 只收安静朗读视频：真实对话场景会明显掉点。
- 没有授权记录：后期无法合法发布模型或数据。

## 9. 最小试点方案

1. 选 3–5 个有授权、字幕质量较好的视频。
2. 提取 1–2 小时音频，抽出字幕并人工校对 30 分钟。
3. 做 VAD 切分和说话人标记，试跑一次 Whisper 伪标注。
4. 让母语者逐字校对，统计每小时产出和错误类型。
5. 根据试点结果决定是否批量处理。
